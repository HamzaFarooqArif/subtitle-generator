    Translate

    This step sends your transcript to whichever translator you paste it into. Everything else here runs offline — the audio never leaves this machine. Copying the text out is the one point where that changes. Unremarkable for a film; for personal recordings it's your call to make deliberately.

    Automatic

    API keys

    Keys are stored in settings.local.yaml, which is gitignored — you can also paste them straight into that file, or set SGEN_GOOGLE_API_KEY / SGEN_DEEPL_API_KEY in the environment to keep them off disk. Both services give 500,000 characters a month free — about 300 files the size of a 25-minute video, so you will probably never pay.

    Where to get it: create a project → enable the Cloud Translation API → link billing → Credentials → Create credentials → API key. Billing must be active even for the free allowance, so a card is required. Worth setting a budget alert, and restricting the key to the Translation API.

    Where to get it: sign up for DeepL API Free → Account → API keys. Free keys end in :fx and are detected automatically. Which languages it can reach is read from DeepL itself, so the list stays right as the service adds more.
